# Hackathon-May23

FRC robotics toolkit built for the 2026 REBUILT season. Three projects, one repo.

## Projects

### `APP/Hackathon-May23` — Robotify App

Main Vite + React + TypeScript app powered by the Google Gemini API. Features:
- Smart Scouting — AI-ranked alliance pick lists
- Game Rules Q&A — Ask rules in plain English
- Strategy Builder — Match strategy targeting Ranking Points
- WPILib Code Snippets — Java/Python copy-paste ready
- Rookie Checklist — Kickoff to alliance selection walkthrough
- 24/7 AI Mentor

### `APP/dashboard-pwa (3)` — Dashboard PWA

Next.js dashboard with Radix UI components. PWA-ready app shell with Vercel analytics.

### `prisma-landing` — Landing Page

Vite + React + Tailwind CSS landing page for Robotify. Uses Framer Motion animations and a bento-grid feature layout.

## Quick Start

```bash
# Robotify App
cd APP/Hackathon-May23
npm install
npm run dev

# Dashboard PWA
cd "APP/dashboard-pwa (3)"
npm install
npm run dev

# Landing Page
cd prisma-landing
npm install
npm run dev
```
